📊 HR Analytics Dashboard – Power BI Project

📌 Project Overview

The HR Analytics Dashboard is an interactive Power BI project designed to analyze employee data and provide meaningful insights into workforce performance and attrition. The dashboard helps HR professionals understand employee trends and supports data-driven decision-making.

---

🎯 Objectives

- Analyze employee attrition.
- Monitor key HR metrics.
- Identify departments with high attrition.
- Understand employee demographics.
- Create an interactive dashboard for HR analysis.

---

🛠️ Tools & Technologies

- Power BI
- Microsoft Excel
- Power Query
- DAX (Data Analysis Expressions)

---

📂 Dataset

The dataset contains HR employee information, including:

- Employee ID
- Age
- Gender
- Department
- Job Role
- Education
- Marital Status
- Salary
- Attrition
- Years at Company
- Job Satisfaction
- Performance Rating

---

📊 Dashboard KPIs

- 👥 Total Employees
- 🚪 Attrition Count
- 📉 Attrition Rate
- ✅ Active Employees
- 🎂 Average Age

---

📈 Dashboard Visuals

- Attrition by Department
- Attrition by Gender
- Attrition by Education
- Attrition by Age Group
- Attrition by Job Role
- Interactive Slicers for Filtering Data

---

💡 Business Insights

- Monitor the overall employee attrition rate.
- Identify departments with higher employee turnover.
- Compare attrition across different age groups and genders.
- Analyze workforce distribution by education and job role.
- Support HR managers in making data-driven decisions.

---

🚀 Skills Demonstrated

- Data Cleaning
- Data Transformation
- Data Modeling
- DAX Measures
- KPI Development
- Interactive Dashboard Design
- Business Insight Generation
- Data Visualization
